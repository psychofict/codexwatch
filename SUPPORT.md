# Getting help

- **A number looks wrong, or something broke:** open a [bug report](https://github.com/psychofict/codexwatch/issues/new?template=bug_report.yml).
  Run `codexwatch doctor` first; it prints counts and paths only, so it is safe to paste.
- **A question, or an idea to talk through:** open an
  [issue](https://github.com/psychofict/codexwatch/issues/new?template=feature_request.yml).
- **A security problem:** report it privately through a
  [security advisory](https://github.com/psychofict/codexwatch/security/advisories/new).
  Never paste an `auth.json`, a token or a session log anywhere public.
